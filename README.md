# Document Backend

Сервис извлекает структурированные данные из изображений документов через HTTP API и фоновые обработчики. Полученные значения являются кандидатами и требуют проверки человеком; результат может быть неполным или неточным.

## Запуск через Docker Compose

Нужны Docker Engine и плагин Docker Compose. Первая сборка требует доступа в сеть, чтобы скачать закреплённые RussianDocsOCR runtime и модельные файлы. Go и Python на хосте устанавливать не требуется.

```sh
git clone https://github.com/EverlastingHolder/document-backend.git
cd document-backend/deploy/portable
docker compose up -d --build
```

HTTP endpoint по умолчанию доступен на `http://127.0.0.1:8080`. Состояние сервисов и health можно проверить командой:

```sh
docker compose ps
```

Self-hosted Scalar API Reference с интерактивной документацией доступен на
`http://127.0.0.1:8081`; его страница и JavaScript загружаются локально.
Чтобы выполнять защищённые запросы, нажмите **Авторизовать** в верхней панели:
Scalar сам создаст и подключит доступ, вручную генерировать токен не нужно.
Авторизация действует только в текущей вкладке и сбрасывается при перезагрузке.
Оба опубликованных порта по умолчанию доступны только локально; руководство
по portable Compose описывает явное открытие доступа в LAN.

Для доступа из локальной сети скопируйте `deploy/portable/.env.example` в
`deploy/portable/.env` и задайте `PASSPORT_PUBLIC_BIND` равным частному IPv4
адресу Linux-хоста. Ограничьте входящий TCP 8080 firewall-правилом для
доверенной сети. Текущий debug APK можно направить на `http://<адрес-хоста>:8080`;
release APK требует HTTPS. LAN forwarding через WSL2 отдельно не проверен.

Остановить сервисы, сохранив данные в именованных volumes:

```sh
docker compose down
```

Не добавляйте `--volumes`, если нужно сохранить данные. Настройка LAN и другие параметры описаны в [руководстве по portable Compose](deploy/portable/README.md). Список API операций приведён в [контракте API](api/openapi.yaml).
