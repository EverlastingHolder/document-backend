# Инструкции для проекта

Сначала прочитайте [README](README.md), [архитектуру](docs/ARCHITECTURE.md), [контракт API](api/openapi.yaml) и соответствующие документы из [docs](docs/).

- Публичный API реализуется на Go. Python используется только для внутреннего RussianDocsOCR runtime и не публикует порт наружу.
- Согласованно обновляйте контракт, каноническую модель результата и документацию при изменении требований.
- Для практических задач делегируйте работу workers `gpt-6-luna` с reasoning `high`; не создавайте вложенных субагентов, одновременно не более четырёх workers. Главный агент отвечает за план и проверку результата.
- До отдельного запроса не запускайте полный аудит. В этом репозитории пока документация и черновик контракта, а не работающий сервис.
