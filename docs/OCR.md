# OCR и национальная MRZ

## Реализованный срез

В Go добавлен строгий parser машинно-читаемой записи внутреннего паспорта РФ по приложению 24 к приказу МВД № 773. Он принимает две уже собранные строки по 44 ASCII-символа, разбирает поля по национальным позициям и проверяет четыре применимые контрольные цифры. Это не generic ICAO TD3 parser. Общие значения символов и алгоритм контрольных цифр сверяются с [ICAO Doc 9303, Part 3, §4.9](https://www.icao.int/sites/default/files/publications/DocSeries/9303_p3_cons_en.pdf); раскладка и modified-CLEER — с [приложением 24 к приказу МВД №773](https://epp.genproc.gov.ru/upload/iblock/701/11rtwhq8z58el7ebz3gm0lqtlnz21y86.pdf).

Parser не обрезает, не дополняет и не исправляет переданные строки. Сборщик наблюдений может выполнить ограниченную нормализацию пробелов и известных визуальных кириллических/латинских вариантов перед передачей в parser; исходные OCR-строки остаются в диагностике. Недостающие строки и неизвестный профиль дают `indeterminate`, некорректная структура или несовпадение контрольной цифры — `invalid`. `valid` означает внутреннюю согласованность распознанного кандидата, а не подлинность документа и не точность OCR.

Дата рождения сохраняется как `YYMMDD`; неизвестные месяц и/или день, записанные в национальной строке как `00`, остаются неизвестными компонентами. Двухзначный год не расширяется до века. Полная дата из VIZ может разрешить год только при валидной ISO-дате и совпадении всех известных MRZ-компонентов. Несовпадающие или неполные данные остаются на ручную проверку.

Имена транслитерированы по национальной таблице и не защищены контрольными цифрами. Parser отмечает неоднозначные составные части и возможное усечение. Знаки пунктуации в кодировке отсутствуют, а дефис представлен разделителем, поэтому исходное написание нельзя гарантированно восстановить. Результат любого поля остаётся предложением для проверки человеком.

Внутренняя интеграция Go принимает observations v2 и имеет политики `off` и `augment`; по умолчанию используется `off`. Режим `augment` добавляет MRZ-диагностику и сопоставляет только согласованные общие поля с VIZ. MRZ не содержит места рождения и полного наименования органа выдачи; эти поля извлекаются отдельно из видимой зоны. Внешний OpenAPI контракт этим срезом не изменён.

Локальный экспериментальный image pipeline может создавать независимые MRZ observations через RapidOCR на CPU и дополнительно через установленный Tesseract. Tesseract необязателен; его отсутствие сохраняется как состояние reader, а не как ошибка всего потока. Эти компоненты и схема handoff не являются развёрнутым публичным OCR-сервисом.

## Экспериментальные source tiles (observations v3)

Внутренняя схема [observations v3](../ocr/schema/observations-v3.schema.json) допускает до шести `source_tile` OCR-проходов: целочисленный crop без поворота и точная трансляция координат обратно в EXIF-нормализованную систему исходного изображения. Строки tile остаются обычными VIZ-наблюдениями с provenance исходного pass. Обработчик использует их только при явном `PassSet: all`; путь по умолчанию остаётся `original`. Это offline эксперимент, выключенный по умолчанию; он не меняет публичный HTTP API. Ограничения схемы и синтетические тесты не являются оценкой OCR-точности, и заявлений о приросте качества нет.

## Граница проверки

Структурные и checksum-тесты parser/integration не измеряют качество распознавания на фотографиях. Для этого среза ещё не выполнена отдельная оценка OCR, сопоставления полей, ложных заполнений, пропусков, пользовательских исправлений, времени и памяти. Численные заявления о точности или производительности не делаются.

Для локального offline эксперимента реализован opt-in source-image маршрут с попыткой регистрации страниц, Go-планированием ROI и PaddleOCR-VL sidecar; см. [автоматические VL ROI](OCR_AUTO_VL.md). Ограниченное after-v2 сравнение на пяти development-изображениях завершено, но не является held-out оценкой. Это не production OCR runtime и не публичная функция API; широкая проверка качества и поддержка произвольных вариантов документа остаются открытыми.
