# Внутренний OCR runtime и handoff

Python-инструменты в `ocr/experiments` формируют внутренние OCR observations; схема v2 описана в [observations-v2.schema.json](schema/observations-v2.schema.json). Handoff содержит исходные строки OCR, reader/pass, score и координаты в системе пикселей исходного EXIF-нормализованного изображения. Он не является публичным API и может содержать персональные данные; отчёты и scratch-каталоги для реальных изображений должны оставаться приватными.

## MRZ-проход

Экспериментальный региональный pipeline выделяет область-кандидат MRZ и может получить observations через RapidOCR на CPU. Если локально установлен Tesseract, он может выполнить дополнительный независимый проход. Tesseract необязателен: отсутствие binary фиксируется как `tesseract_unavailable`. Reader и pass metadata сохраняются в observations v2.

Go parser для национальной MRZ внутреннего паспорта РФ принимает две строки после ограниченной upstream нормализации OCR-кандидата и проверяет структуру, modified-CLEER и check digits. Сам parser не обрезает, не дополняет и не корректирует строку. Политика `off` (по умолчанию) не запускает MRZ-сборку; `augment` добавляет MRZ-диагностику и предложения для общих полей VIZ. Raw строки сохраняются отдельно от ограниченно нормализованных кандидатов.

Даты сохраняют национальный `YYMMDD`, включая неизвестные компоненты месяца/дня, и не расширяют год до века. VIZ разрешает дату только при валидном полном ISO-значении и совпадении известных компонентов. Имена и пол не защищены check digits; составные имена и возможное усечение отмечаются как неоднозначные. Ни один parser status не подтверждает подлинность документа. Все предложенные значения требуют проверки человеком.

## Модель и режим работы

RapidOCR — reader на CPU. Tesseract — опциональный дополнительный reader. Точные версии runtime и модельные артефакты фиксируются в выбранном запуске; любые модели и обучающие данные хранятся вне Git. Используются готовые веса без обучения или fine-tuning. Поддержка ускорителей и целевой матрицы компьютеров не заявлена без отдельной проверки.

Локальные smoke и evaluation harness описаны в [experiments/README.md](experiments/README.md). Успешная работа reader, заполнение TSV, прохождение parser tests или совпадение check digits сами по себе не показывают точность на фотографиях паспорта. Для реализованного среза ещё предстоит отдельная оценка на разрешённых данных; до неё численные заявления о точности и производительности не делаются.

## Граница реализации

Внешний OCR/API service, сборка production image pipeline, deployment и операционные лимиты не входят в текущий срез. Регистрация геометрии страниц, коррекция перспективы, идентификация варианта бланка и ROI видимых реквизитов остаются предлагаемыми стадиями. Текущие coordinates/группировка MRZ observations не являются регистрацией страницы или шаблонным классификатором.

Не добавляйте реальные паспортные изображения, сырые строки MRZ, распознанные имена/номера или эталоны в репозиторий и обычные тестовые fixture.
