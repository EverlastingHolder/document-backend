# Развёртывание

Go API и Python PaddleOCR runtime выполняются на одном компьютере. Цель — большинство обычных настольных компьютеров и ноутбуков; планируемая матрица проверки — Windows/Linux/macOS на x86_64/arm64, без гарантии универсальной поддержки любого устройства. CPU — базовый режим, GPU необязателен и используется при поддержке runtime и оборудования. Минимальные версии ОС, CPU и объём RAM определит пилот. Контейнерная упаковка — необязательный вариант, совместимость которого нужно проверить; возможен нативный запуск. Go API должен быть доступен Android по стабильному HTTPS endpoint из любой сети через интернет. Если используются контейнеры, только Go API доступен клиенту, а OCR runtime вызывается по внутренней сети и не публикует порт на хост.

`compose.yaml` может появиться после реализации и проверки совместимости, когда образы, внутренний протокол, health checks, конфигурация, временные каталоги и завершение запросов будут определены. Сейчас compose-файла, Dockerfile, образов и команд запуска нет. Локальная разработка может запускать компоненты нативно; проверенных команд запуска пока нет.

При развёртывании компьютер должен быть включён и подключён к сети, а Go API опубликован по стабильному HTTPS endpoint, доступному из интернета. Домен, тип аутентификации и способ публикации — прямое подключение, reverse proxy или туннель — пока не выбраны. Для разработки Android может обращаться к компьютеру в локальной сети. Операционные значения лимитов остаются открытыми. Не помещайте секреты или ключи в Android APK.

Временные изображения должны удаляться после завершения обработки как при успехе, так и при ошибке. Не записывать фото, распознанный текст и иные персональные данные в логи. Утверждения о соответствии требованиям или о допустимом месте хранения здесь не делаются.
